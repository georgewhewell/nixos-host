This directory holds the remaining ESPHome external components that are still needed for the ESP32-P4 MIPI camera path.

As of March 20, 2026, upstream ESPHome already provides `api`, `esp32_camera_web_server`, `esp32_hosted`, and `esp_ldo`, so those are no longer vendored here.
